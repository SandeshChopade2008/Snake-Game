# Snake Game

A browser-based Snake game built with HTML, CSS, and JavaScript.

Guide the snake to the food, grow your score, and avoid hitting the walls or your own tail.

## Features

- Move with the arrow keys or W, A, S, D.
- Pause and resume with Space or the on-screen button.
- Restart after a game ends.
- Track the current score and save the best score in the browser.
- Increasing speed as the game progresses.

## Run locally

1. Select **Code → Download ZIP** on this repository.
2. Extract the ZIP file.
3. Open `index.html` in your browser.

## Technologies

- HTML for page structure
- CSS for styling and layout
- JavaScript for movement, collision detection, scoring, and browser storage

## Project files

- `index.html` — game page and controls
- `style.css` — visual design
- `script.js` — game logic
